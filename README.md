# Plim Plim · Plantilla editable

Abre index.html o publica esta carpeta completa con GitHub Pages desde main / (root). No necesita compilación. La invitación se muestra directamente, sin botón de descubrimiento ni pantalla de apertura.

Edita datos.js para personalizar nombre, edad, fecha ISO, zona horaria, lugar, mapa, contactos, textos, portada, escenario y galería. Todos los datos actuales son ficticios; modoDemo es true y los teléfonos y mapa están vacíos. No se envían mensajes reales ni se registran invitados.

Usa fotos para la galería, portada.imagenes para el personaje principal y ambientacion para el escenario. Añade tus imágenes en assets/ y usa rutas relativas. Para activar WhatsApp configura un número mexicano de 12 dígitos (52 más 10) y cambia modoDemo a false.

Las fuentes y las imágenes nuevas de ambientación están incluidas localmente. La portada de Plim Plim y todas las imágenes temáticas se incluyen localmente.

Los prompts y los archivos finales se detallan en RECURSOS-VISUALES.md. Conserva assets/, estilos, scripts y .nojekyll al copiar la plantilla a otro repositorio.
